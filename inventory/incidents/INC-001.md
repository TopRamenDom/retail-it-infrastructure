# Incident INC-001 — POS-02 Network Outage

## Device

**POS-02**
IP Address: `192.168.56.102`

## Issue

POS-02 was reported offline by the retail device health monitoring script and could not be reached from the Kali administration server.

## Reported Symptoms

* POS-02 reported `OFFLINE` in `device-health.sh`
* Ping attempts returned `Destination Host Unreachable`
* SSH connectivity on TCP port 22 was unavailable

## Troubleshooting Performed

1. Ran the device health monitoring script and confirmed POS-02 was offline.
2. Tested connectivity with:

   ```bash
   ping -c 4 192.168.56.102
   ```
3. Checked the Kali routing table with:

   ```bash
   ip route
   ```
4. Confirmed Kali still had a valid route to the `192.168.56.0/24` network.
5. Tested SSH connectivity to POS-02 on TCP port 22.
6. Checked POS-02 network interfaces with:

   ```bash
   ip -br addr
   ```
7. Found the `enp0s8` Host-Only network interface in a `DOWN` state.

## Root Cause

The `enp0s8` network interface on POS-02 was disabled, preventing communication across the internal `192.168.56.0/24` lab network.

## Resolution

Restored the network interface with:

```bash
sudo ip link set enp0s8 up
```

## Verification

* Confirmed `enp0s8` returned to the `UP` state
* Confirmed POS-02 retained `192.168.56.102`
* Successfully pinged the Kali administration server
* Re-ran the device monitoring script
* POS-02 returned to `ONLINE` status

## Result

Connectivity was fully restored and monitoring confirmed that POS-02 was reachable again.
